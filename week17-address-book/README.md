# 第 17 周：命令行通讯录

本周建议用时：8–10 小时。把前面学过的类、`vector`、`map` 或线性查找、文件输入输出和 CMake 收成一个能运行的小程序。做不完每一处加分项也没关系，先让增、查、列、删在内存里工作。

## 本周目标

- 读懂一个分成三个部分的程序：数据（`Contact`）、容器（`AddressBook`）、菜单（`main`）。
- 实现添加、列出、按姓名查找、按姓名删除。
- 用文本文件保存和加载。格式自己定，建议每行一个人：`姓名|电话|邮箱`。
- 用第 16 周的方式编译目标 `week17_address_book`。

## 概念笔记

程序分成这些文件：

| 文件 | 职责 |
| --- | --- |
| `contact.h` / `contact.cpp` | 一个联系人：姓名、电话、邮箱 |
| `book.h` / `book.cpp` | 通讯录：增删查改和存盘，内部用 `vector<Contact>` |
| `main.cpp` | 菜单循环。它不直接操作 vector |

菜单已经能运行：选 `0` 退出，选 `1`–`5` 会调用对应函数。那些函数目前只打印「还没完成」。你的工作在 `book.cpp`，必要时给 `Contact` 加一个修改电话的函数。

建议的完成顺序：

1. `add`：把联系人放进 `contacts_`。
2. `list`：空表打印「通讯录是空的」，否则逐个打印编号、姓名、电话、邮箱。
3. `find_by_name`：姓名里包含关键字就算找到。先做「完全相等」也可以，再改成包含。
4. `remove_by_name`：按完全相等的姓名删除第一个，删掉返回 `true`。
5. `save` / `load`：用 `|` 分隔。加载前想清楚：是清空再读，还是追加。建议清空再读，并在注释里写明。

查找不一定要用 `map`。通讯录很小，`vector` 上逐个比较就符合要求。如果你想加分，可以另外用 `map` 做索引，但要处理重名，这比线性查找容易出错，留到基本功能都完成之后。

编译和运行：

```bash
cmake -S . -B build
cmake --build build --target week17_address_book
./build/bin/week17_address_book
```

不要单独用 `g++` 编译 `book.cpp`，它没有 `main`。

运行时生成的 `contacts.txt` 已经写在 `.gitignore` 里，不会被提交。

## 自测
